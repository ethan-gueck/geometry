A triangle is typed by how many of its sides are equal, and by its largest angle against 90°.

a = b = c, A = B = C = 60° equilateral  ·  a = b ⟺ A = B isosceles

max(A, B, C) < 90°, = 90°, > 90° acute, right, obtuse

a > b ⟺ A > B  ·  Area = (√3 / 4) s² equilateral

    “Isosceles” is Greek for “equal legs”; “scalene” for “uneven”. Every equilateral triangle is also isosceles: it has at least two equal sides.

    Three sides
    a, b, c
    the side lengths, each opposite the angle of the same capital letter: a faces A, b faces B, c faces C
    A, B, C
    the angles at the three corners, in degrees; side c = AB lies along the bottom
    s
    the side length of an equilateral triangle, s = a = b = c
